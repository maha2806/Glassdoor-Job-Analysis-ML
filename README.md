# Glassdoor Job Analysis and Prediction using Machine Learning

## Project Overview

This project analyzes Glassdoor job data and implements machine learning algorithms to identify patterns and generate predictions.

The project demonstrates:

- Data preprocessing
- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine Learning model building
- Hyperparameter tuning
- Model evaluation
- Model saving for deployment

---

## Dataset Information

Dataset: Glassdoor Jobs Dataset

Features:

- Job Title
- Salary Estimate
- Company Name
- Rating
- Industry
- Sector
- Revenue
- Location
- Founded Year
